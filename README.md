# 《月下櫻落》 Official Lore Bible

> 一部以宮廷權謀、江湖恩怨與女性群像為核心的原創古裝劇世界觀。

---

## 專案介紹

《月下櫻落》 Official Lore Bible 是本作品的官方世界觀資料庫。

本 Repository 收錄所有正式（Canon）設定，包括：

- 世界觀
- 人物設定
- 各季劇情
- 組織介紹
- 世界時間線
- 番外故事
- 歷史設定（Archive）

所有資料皆以 GitBook 作為主要閱讀平台，GitHub 則作為版本管理與內容維護。

---

## Canon 與 Archive

本 Repository 分為兩種設定：

### Canon（正式設定）

目前劇情唯一採用的設定。

所有角色、事件與世界觀皆以 Canon 為準。

---

### Archive（歷史設定）

保存早期抽卡人生、廢案與舊版本設定。

Archive 僅作為創作歷程紀錄，不代表正式劇情。
