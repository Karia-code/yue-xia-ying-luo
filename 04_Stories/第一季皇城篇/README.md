# 第一季・皇城篇

> **當皇帝的面容可以複製，聖旨可以偽造，名字可以抹去——天下真正需要辨認的，便不再只是誰真誰假，而是誰願意為自己的選擇負責。**

---

## 篇章介紹

《皇城篇》為《月下櫻落》第一季的主要故事線之一。

故事始於大宋皇城的上元燈會。

花燈照徹長街，北境戰事與儲位之爭卻已在繁華之下悄然逼近。護國公府嫡長女珞妍奉旨入京，燕王雪陸自北境歸來，雪晨、芮夜、詠而歸等人也因各自追查的案件，逐步被捲入皇城深處的秘密。

一枚青龍佩、一支來歷不明的替身軍，以及能夠改變面貌、聲音與記憶的黃字藥，將眾人的視線引向雪家地下。

在那裡，人的姓名可以被抹除，身份可以被重新製造，皇帝也可以由另一個人代替。

隨著天地玄黃四脈、帝型制度、地下血庫與主鐘逐一浮現，皇城中開始同時出現數名擁有相同面貌與記憶的人。真假端王、兩個雪晨、梁進與帝型一，以及被囚禁五年的原主皇帝，使整個朝廷陷入前所未有的帝位危機。

然而，故事真正追問的並不是「誰才是真的」。

而是：

當一名替身已經以另一個人的身份生活多年，他所經歷的人生是否全都算假？

當真正的皇帝建立帝型、使用藥物控制臣民，他是否只因血脈為真，便能免除責任？

當一道命令來自皇帝、軍令、藥物或早已死去的人，執行者是否仍有拒絕的權利？

皇城篇從一場花燈夜的暗殺與軍情疑案開始，最終走向皇權、身份、服從與選擇的全面崩解。

眾人必須阻止第七鐘敲響，也必須在主鐘停止之後，重新決定這個天下應該如何運作。

---

## 故事定位

* 時間：第一季
* 地點：大宋皇城、雪家地下、紫宸殿、承天門及京畿地區
* 篇幅：全四十章
* 類型：朝堂權謀、懸疑、替身陰謀、身份議題
* 核心主題：真假身份、皇權與服從、名字與記憶、個人選擇與責任
* 故事定位：第一季主要主線之一，與《後宮篇》同時發生

---

## 主要角色

### 核心角色

* **珞妍**
  護國公府嫡長女，精通醫術。奉旨入京後，逐步追查黃字藥、血庫與帝型制度，也是眾人在多次中毒與藥令失控中最重要的醫者。

* **雪陸**
  大宋三皇子、燕王，長年鎮守北境。面對真假聖旨、軍令與儲位之爭，他逐漸拒絕以血脈或兵權決定天下，並成為阻止主鐘與皇城兵變的重要力量。

* **雪晨**
  雪家養子，擅長分析局勢、機關與人心。在帝型與身份混亂之中，他協助眾人辨認命令的漏洞，也陪伴顧影確認自己不必成為任何人的替身。

* **芮夜**
  江湖出身，行事果斷，擅長暗器與近身作戰。她始終站在被控制與被替代者的一方，並多次在主鐘、壽安宮與承天門事件中阻止機關與滅口。

* **詠而歸**
  錦衣衛指揮使。負責查驗宮中密令、北鎮撫司舊檔與梁進暗線，也在發現錦衣衛遭滲透後，重新整頓秘密拘押與密檔制度。

## 與其他故事線的關聯

《皇城篇》與《後宮篇》並非前後續，而是發生於同一時期的兩條故事線。

```text
第一季・皇城篇
        ⇅ 時間同步
第一季・後宮篇
```

皇城篇聚焦於朝堂、帝型、皇權與身份制度。

後宮篇則從宮廷內部的人物、妃嬪與女性處境展開。

兩條故事中的人物、情報與事件會彼此影響，並在第二季《蝶歸長夜》中正式交會。

皇城篇建立的新政、覆名司、帝型案與主要角色去向，也將成為第二季朝局與人物選擇的重要背景。
